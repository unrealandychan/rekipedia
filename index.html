Features

Everything you need, nothing you don't

rekipedia is a zero-config, AI-native knowledge layer for any codebase.

⚡

Zero Config Scan

Run reki scan . and get a full wiki instantly. No API keys required with --no-llm.

🎯

Grounded Q&A

Ask questions about your repo in plain English. Every answer includes precise file:line citations.

🔌

MCP Ready

One command to expose your knowledge base as an MCP server. Plug directly into Claude Code or Cursor.

📝

Committable Wiki

Generated docs are plain markdown files you can commit to git. Version-control your knowledge base.

🔄

Incremental Updates

Only re-indexes changed files. Re-scans are instant even on large monorepos.

🔥

Hotspot Detection

Automatically identifies high-churn files and complex modules so you focus on what matters.

🏘️

Community Sharding

Run --community-sharding to cluster tightly-coupled files together. LLMs get denser, higher-quality context.

🕸️

Graph Intelligence

Three new MCP tools: get_god_nodes, shortest_path, get_community. Agents can now reason about your architecture graph directly.

How it works

From zero to AI-powered in 3 steps

1

Scan

Run reki scan . to index your codebase. Works offline with --no-llm. Zero configuration required.

2

Ask

Run reki ask "..." to get grounded answers with exact file:line citations from your own code.

3

Connect

Run reki mcp to spin up an MCP server. Instantly available inside Claude Code, Cursor, and any MCP client.
